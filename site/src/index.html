About this viewer

This is a view-only subset of the notebook interface Servette was written in. The cells are the authored Markdown sources (src/*.md) fetched straight from the repository — the same files servette.py is generated from — with the prose rendered, the rationale notes as callouts, and the Python highlighted.

The icon strips along each edge are the activity bars. On the left: the Navigator (the file list, each file's cells, and search across all five files), the assistant, and Settings at the bottom — one panel at a time. On the right: the Preview pane (the open file as one plain rendered document) and the Call Map (the open file's functions and who calls whom — click a function to jump to it). Click an icon to open or close its panel. The viewer always starts with both sides closed and INIT.md open.

There is also an optional reading assistant — Servette itself, answering for its own code. It runs entirely in your browser (WebLLM over WebGPU — nothing you type leaves your machine), and because the model is yours, the tokens are too: ask Servette about Servette as much as you like, with no accounts, no API keys, and no limits. Set it up in Settings → Agentic Reading; it reads whichever source files your question needs.

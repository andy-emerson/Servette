These checks only reach what a browser can see. The rest of Servette runs where this page cannot look. On the request path it redirects HTTP to HTTPS, gzip-compresses what it sends, rate-limits abusive clients, can sit behind a password, and routes each domain to its own site — these results describe only the one you reached. Off the request path it runs as a supervised service that restarts on boot, drops privileges once the ports are bound, renews its certificate automatically, and accepts new site content only as signed bundles the operator pulls on purpose. And nothing above happens while it is answering you: by design, no request ever reaches a write. servette.org describes the whole of it.

This page ships inside Servette itself and runs on this site's own domain — that is why it can read what it tests. Served by Servette — The Simple, Secure, Static-Site Server.
